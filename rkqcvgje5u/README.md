# お礼LINEメーカー

## 何をするツールか
査定後のお客様に送るお礼LINEのたたき台を作るページです。
「今日の結果（成立／不成立／問い合わせ）」と「来店回数（1回目／2回目／3回目〜）」を選び、その方だけの一言を入れると文面ができあがります。文面は自由に手直しでき、「コピーする」でLINEに貼り付けて送信します。

- 公開URL：https://norihikohinoda-droid.github.io/dashbord/rkqcvgje5u/
- 検索エンジンに載らないよう `noindex` を設定しています。URLは店舗スタッフにだけ伝えてください。
- お客様名や一言は、その端末のブラウザの中だけで使われます。どこにも送信・保存されません（担当者名だけ、その端末に保存されます）。

## 必要な準備
- インターネットにつながるスマホ・タブレット・PCのブラウザ（Chrome / Safari など）
- アカウントやインストールは不要です

## 起動の仕方
1. 上の公開URLをブラウザで開く（店舗端末ではブックマークかホーム画面に追加しておく）
2. 結果と来店回数をタップし、名前と一言を入れる
3. 「コピーする」を押し、LINEのトーク画面に貼り付けて送信する
4. 「次のお客様へ」で入力をリセットする

### 文面を変えたいとき
`index.html` の中の次の部分を書き換えて、GitHubにプッシュします。1〜2分で公開URLに反映されます。
- `OPENING`：来店回数ごとの書き出し
- `RESULT`：結果ごとの文
- `CLOSING`：来店回数ごとの締め
- `CHIPS_COMMON` / `CHIPS_BY_RESULT`：一言の候補

## よくあるエラーと対処
| 症状 | 対処 |
| --- | --- |
| 「コピーする」を押してもコピーされない | 文面が選択された状態になるので、長押しして「コピー」を選ぶ |
| 文面を直したのに古いまま | 1〜2分待ってから、ページを再読み込みする |
| 担当者名が毎回消える | ブラウザのプライベート（シークレット）モードをやめて通常モードで開く |
| 「〇〇が残っています」と出る | 文面の「〇〇」を書き換えてから送る |
| ページが404になる | GitHubのリポジトリ設定 → Pages が有効か、フォルダ名が `rkqcvgje5u` のままか確認する |
